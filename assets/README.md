# App icon

Generated with the built-in image generation tool for URL Parser. `AppIcon.png` is the retained source asset, with an alpha channel. `scripts/build-icon.sh` converts it into the standard macOS `.icns` sizes during packaging.

Prompt:

Use case: logo-brand. Create a polished macOS app icon for URL Parser, a tiny native developer tool for bidirectional URL and JSON editing. Square 1024x1024. A single rounded-square soft ivory app tile centered with generous safe margins, simple bold purple curly braces embracing a small green chain link; communicates code and URL conversion. Flat precise geometric shapes with restrained macOS dimensional shading, legible at 32px. No letters, no words, no watermark, no extra objects. Tile occupies about 82 percent of canvas. Outside the tile use perfectly uniform solid magenta #FF00FF chroma-key background, no shadows or reflections outside tile, no magenta in icon itself. Crisp silhouette and simple opaque materials.
